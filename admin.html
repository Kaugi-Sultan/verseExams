🔥 Firebase Database

📌
This is the most important integration. Without it, bookings, chats, and feedback ONLY save on whichever single device/browser a student or admin is using — they will not appear across devices. To fix this permanently:

1. Go to console.firebase.google.com → Create a free project
2. Build → Firestore Database → Create database → Start in test mode
3. Project Settings (⚙️ icon) → scroll to "Your apps" → Add app → Web (</>)
4. Copy the firebaseConfig values
5. Paste them into the FIREBASE_CONFIG object at the top of the <script> tag in both index.html AND admin.html
6. Save both files and re-upload — bookings will now sync everywhere instantly.

1. Create a Google Sheet with these columns: Timestamp, Name, Email, Phone, Country, Service, Platform, Course, Deadline, Instructions
2. Extensions → Apps Script → paste the webhook script
3. Deploy as Web App → Anyone → copy the URL here
